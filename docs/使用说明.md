# 中药处方加工与取药管理系统使用说明

本文面向全局管理员、门店管理员和门店员工，介绍管理端 Web 与管理员微信小程序的登录方式、日常业务流程以及各功能模块的操作方法。

## 1. 使用前准备

### 1.1 访问入口

| 使用对象 | 入口 | 主要功能 |
| --- | --- | --- |
| 全局管理员、门店管理员、门店员工 | 管理端 Web（访问地址由部署人员提供） | 门店、处方、加工、包裹、库存和系统设置 |
| 全局管理员、门店管理员、门店员工 | 管理员微信小程序 | 移动端概览、处方、加工、包裹、斗谱和库存业务 |

使用前请向系统负责人获取管理端 Web 地址和管理员账号。账号应由全局管理员创建或分配，并确认所属门店和角色正确。

### 1.2 账号与权限

- **全局管理员**：可查看和管理全部门店，负责基础资料、账号、通知、日志和系统配置。
- **门店管理员**：只能管理所属门店的数据，可维护门店业务、员工/用户、加工、包裹、库存和部分门店设置。
- **门店员工**：用于门店现场操作（如加工和取货核销），只能访问系统开放给员工的页面和所属门店数据。

## 2. 管理端 Web 登录与退出

1. 打开管理端 Web，在登录页输入手机号或用户名及密码。
2. 需要长期保持登录时勾选“记住登录状态”，再点击“登录”。
3. 管理员登录后默认进入“首页”。
4. 点击右上角头像，可进入“个人资料”或“退出登录”。共用电脑操作结束后应退出登录。

登录后页面会根据角色自动隐藏无权访问的菜单。全局管理员在涉及门店的页面可选择“全部门店”或指定门店；门店账号不需要重复选择门店。

## 3. 管理员微信小程序登录

### 3.1 登录与退出

1. 打开已发布的管理员微信小程序，在登录页切换到“管理员”。
2. 输入管理员手机号或用户名、密码，点击“管理员登录”。小程序只允许管理员和门店员工进入管理页面。
3. 登录成功后进入“概览”。底部导航固定提供“概览、斗谱、加工、包裹、我的”五个入口。
4. 点击“我的 → 退出登录”结束当前会话。共用设备操作结束后应退出登录。

### 3.2 小程序功能入口

- **概览**：查看加工概况、包裹概况；点击统计卡片可直接跳转到对应筛选结果。业务管理区可进入处方、门店调拨、库存差异、E6 药店库存和药店商品盘点。
- **斗谱**：搜索药材和货位，新增/编辑药材绑定，修改斗、柜、冰箱或仓库位置；全局管理员和门店管理员可维护，员工按权限使用。
- **加工**：在“加工计划/待领取”之间切换，按今日待加工、加工中、已完成、加急等统计筛选；支持扫码作业、新建计划、收到通知、开始加工、加工完成、生成包裹、延期、编辑和取消。
- **包裹**：按取货码、手机号、姓名或物品搜索，按门店（全局管理员）、待取/已取和排序筛选；支持新增、编辑待取包裹以及“扫码/取货码核销”。
- **我的**：查看账号、角色和所属门店，修改昵称/用户名/手机号/密码；可查看或修改当前微信绑定。修改密码时需填写确认密码。

小程序页面以卡片和横向操作栏呈现，操作按钮可能需要左右滑动查看。数据权限与 Web 管理端一致，门店账号只能访问所属门店。

## 4. 首次初始化（管理员）

首次上线建议按以下顺序配置，避免创建处方时下拉选项为空：

1. 在“系统管理 → 门店管理”新增并启用门店。
2. 在“系统管理 → 基础资料”维护医生、处方来源、加工方式、通知方式等字典项。
3. 在“系统管理 → 门店账号”创建门店管理员或员工账号，并分配所属门店。
4. 在“系统管理 → 货品项目”维护加工相关商品；需要库存管理时继续配置“斗谱管理”和库存差异。
5. 按需在“短信设置”“邮件设置”“群机器人通知”配置通知渠道并使用测试发送确认配置有效。
6. 按需在“打印设置”检查加工标签、包装标签、取货标签的版式和打印机纸张规格。

## 5. 日常业务教程

### 5.1 新建处方

1. 进入“处方管理”，点击“新建处方”。
2. 选择所属门店（仅全局管理员需要），填写顾客姓名、手机号、医生、处方来源和总价。
3. 外部处方打开“外方”，补充医院、医生和外方备注；普通处方保持关闭。
4. 填写备注后点击“保存”。手机号为选填项；填写时必须是有效的 11 位手机号。
5. 保存后在列表点击处方编号或“详情”，检查顾客、医生、剂数和状态。

处方删除仅适用于尚未建立加工计划的记录。已产生加工批次的处方应通过编辑将状态调整为“已取消”，以保留业务历史。

### 5.2 创建加工计划

1. 进入“加工工作台”，点击“新建计划”。
2. 选择已有处方，或在弹窗中直接新建处方并填写必填资料。
3. 选择加工方式和取货方式：自提、跑腿或快递。选择跑腿/快递时补充地址；快递还需填写快递单号（可在后续补录）。
4. 填写批次号和剂数。一个处方可点击“新增批次”拆分为多个加工计划，所有批次剂数合计必须等于处方总剂数，批次号不能重复。
5. 代煎类加工还需填写袋数/每剂袋数和每袋毫升数；填写服用方法、加工备注和其它备注。
6. 设置优先级（普通/加急）、调度方式（指定日期/等待顾客通知）、计划开工日期、提醒方式和收费状态。
7. 点击“保存”。系统会为每个加工计划生成唯一的 6 位取货码（页面通常显示为 `123-456`），可在详情中打印标签。

### 5.3 排队、开工与完成

1. 在“加工工作台”选择“列表”查看任务，顶部统计卡片可快速筛选今日待加工、逾期、加工中、加急和明日任务。
2. 今日待加工任务可拖动调整队列顺序；需要恢复系统排序时点击“恢复默认排序”。
3. 打开任务详情，核对处方、剂数、加工方式、取货方式和备注后执行“开始加工”。
4. 加工结束时执行“完成加工”。
   - 选择生成包裹：立即创建“待取”包裹，沿用该计划的取货码。
   - 选择暂不生成：只完成加工，之后可在计划详情中手动“生成待取包裹”。
5. 如加工方式包含浸泡、煎煮、打包等工序，可在详情查看工序记录；需要补录时填写工序、分组、设备、起止时间和补录原因。
6. 加工完成后按实际情况确认“已通知”或稍后通知。通知状态可在计划详情中查看和补充。

计划状态依次为：**待加工 → 加工中 → 已完成 → 待领取 → 已领取**。取消只能在允许取消的早期阶段执行，已领取记录不能重复核销。

### 5.4 打印标签

在加工计划或包裹详情点击“打印标签”，选择加工标签、包装标签或取货标签。打印前确认浏览器已允许打印、纸张尺寸与模板一致，并核对顾客姓名、加工码和取货码。标签遗失时可从包裹详情重新打印。

### 5.5 通知顾客

- 计划详情中的“提醒方式”和“通知状态”用于记录通知安排。
- 短信、邮件或群机器人启用前，管理员应在对应设置页填写凭据、保存并执行测试发送。
- 快速处理通知失败时，先查看“系统管理 → 操作日志/登录日志”及通知投递记录，确认手机号、模板变量和渠道余额/权限。

### 5.6 包裹查询与取货核销

1. 进入“包裹管理”，可按取货码、顾客/手机号、状态、门店和日期筛选。
2. 打开“包裹详情”核对物品、收件人、手机号、取货方式和备注；需要时编辑资料或打印标签。
3. 顾客到店时进入“核销”（也可从包裹详情进入），输入 6 位取货码。系统支持输入 `123456` 或 `123-456`。
4. 核对二维码、顾客和物品信息，选择实际取货方式：自提、跑腿或快递。快递方式必须填写/扫描快递单号。
5. 点击“确认核销”，在二次确认框中确认。成功后包裹变为“已取”，记录取货时间、方式和操作人。

已核销包裹会提示“不能重复核销”。若一个处方有多个批次，全部批次领取后处方才会自动完成。

## 6. 其他功能模块

### 6.1 门店调拨

进入“门店调拨”登记调出或归还，填写来源/目标门店、物品、数量和预计归还日期；按实际流程执行确认出库、确认归还或取消。首页的“借出中、部分归还、待调平、逾期调拨”卡片可直接定位异常记录。

### 6.2 库存差异与药店商品盘点

- “库存差异”用于查看期初差异、库存调整、核销和撤销记录，批量导入前先下载模板并使用导入预览。
- “药店商品盘点”中先新建盘点，选择范围后对商品执行初盘；系统标记为待复盘/需调整的记录需再次录入复盘数量，并由管理员二次确认。盘点结束后可导出全部、待复盘或需调整库存清单。
- “斗谱管理”用于维护药材与货位绑定，可导入/导出 Excel；导入前请确保模板列名和编码格式未修改。

### 6.3 E6 处方导入

1. 在“E6 诊所处方导入”查看接口接收的导入记录。
2. 检查门店、顾客、医生、加工方式和剂数；异常记录先修正映射或执行重新校验。
3. 确认无误后执行“确认导入”，系统才会生成正式处方和加工计划。

### 6.4 个人资料

点击右上角头像进入“个人资料”，可修改昵称、用户名、手机号和密码。修改密码时同时填写确认密码；不修改密码请保持密码框为空。保存后建议重新登录验证。

## 7. Android 管理员端（暂留）

Android 管理员端目前尚未完整开发，暂不作为本教程的主要操作入口。当前仅有部分登录、概览和业务查询能力，部分页面仍使用演示数据；关键业务操作请使用管理端 Web 或管理员微信小程序。

## 8. 常见问题

**登录后立即回到登录页**：重新登录并确认账号仍处于启用状态；如仍无法登录，请联系系统负责人。门店账号只能访问所属门店。

**加工方式/医生下拉框为空**：先由全局管理员在“基础资料”创建并启用对应字典项，或检查门店是否已启用。

**无法生成包裹**：确认加工计划处于“已完成”，并检查顾客、取货方式及快递信息是否完整。

**找不到取货码**：在加工计划详情或包裹详情查看；取货码为 6 位数字，页面可能按 `3-3` 格式显示。

**核销失败或重复核销**：重新输入纯数字取货码并核对包裹状态；状态为“已取”的包裹不可再次核销。

**通知未送达**：检查通知渠道配置、模板变量、手机号/邮箱和通知日志；必要时重新测试渠道后再发送。

**打印内容错位**：在“打印设置”检查模板尺寸、字段可见性和浏览器打印缩放，建议使用 100% 缩放并关闭页眉页脚。

## 9. 数据与安全建议

- 录入手机号、处方和取货码前进行二次核对，避免包裹错领。
- 不在聊天群或截图中公开完整手机号、取货码和处方详情。
- 定期查看操作日志和登录日志；离职账号及时停用并回收权限。
- 管理员账号不得共用；人员变更或离职时及时停用账号并回收权限。
- 发现登录异常、数据异常或通知异常时，保留提示信息和发生时间，联系系统负责人处理。
