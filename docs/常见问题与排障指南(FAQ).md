## 1. 硬件外设排障

### Q1.1 桌面扫码枪扫取药二维码没有反应，或者扫出来没有自动触发查询？
- **原因分析**：
  1. 扫码枪未开启**「回车换行符（CR/LF / Enter）」**后缀，导致条码输入后未模拟按下 Enter 键；
  2. 电脑当前输入法处于**中文拼音输入状态**，导致扫描出来的数字/英文被拼音输入法拦截。
- **解决方案**：
  1. **配置回车后缀**：取出扫码枪说明书，找到“设置后缀为 CR (Enter)”或“增加换行”的专用配置条码，使用扫码枪扫描一次；
  2. **切换输入法**：将电脑输入法切换为大写锁定（Caps Lock）或系统原生英文键盘；
  3. **确认焦点**：确保光标已经点击在 Web/小程序「核销输入框」内。

### Q1.2 热敏小票/标签打印机打印出来是白纸，或文字挤压变形？
- **原因分析**：
  1. 热敏纸装反（热敏涂层朝向不正确）；
  2. 浏览器打印缩放比例被设为了“缩放至页面大小”；
  3. 打印机驱动首选项中纸张尺寸与实际标签不符（如实际为 80×50mm，驱动却默认为连续卷纸或小票纸）。
- **解决方案**：
  1. **检查纸张方向**：用指甲在标签纸表面用力划一道，变黑的一面是热敏涂层面，必须朝向打印头安装；
  2. **调整浏览器打印参数**：
     - 目标打印机：选择对应的热敏标签机（如 Gprinter GP-1324D）；
     - 边距（Margins）：必须选择 **「无 (None)」**；
     - 缩放（Scale）：必须选择 **「实际大小 (100%)」**；
     - 选项：取消勾选「页眉和页脚」。
  3. **校准纸张传感器**：长按打印机走纸键（FEED）听到两声蜂鸣后松开，执行自动测纸与间隙识别。

### Q1.3 Android 药房助手扫码时无法提取 SKU 药材码？
- **原因分析**：
  1. 药盒标签表面反光严重、磨损严重或相机未成功对焦；
  2. 药盒标签格式不包含系统预设的 9 位产品数字码规则。
- **解决方案**：
  1. 开启界面右上角的闪光灯补光，保持摄像头距离标签 10~15 厘米处轻微晃动以重新触发自动对焦；
  2. 系统采用**两帧校验防抖机制**，对准条码静止停顿 0.5 秒，识别成功时手机会有震动反馈。

## 2. E6Sync 与 E6 数据库同步排障

### Q2.1 E6Sync 报错：“Cannot open database requested by the login. The login failed.”
- **原因分析**：运行 `E6Sync.exe` 的当前 Windows 登录账户没有访问 SQL Server 目标数据库的权限。
- **解决方案**：
  1. 在 SQL Server 所在主机打开 **SQL Server Management Studio (SSMS)**；
  2. 展开左侧 **安全性 ➔ 登录名**，检查是否存在当前 Windows 用户名（或本地组 `Users`）；
  3. 右键该登录名选择 **属性 ➔ 用户映射**；
  4. 勾选诊所数据库（如 `E6观前街中医诊所`）和药店数据库（如 `E6苏州药店`），在下方的数据库角色成员身份中勾选 **`db_datareader` (只读)**，点击确定保存；
  5. 返回 E6Sync 点击「测试 SQL 连接」重新验证。

### Q2.2 E6Sync 上传订单返回：“HTTP 401: E6接入凭证无效”？
- **原因分析**：`config.json` 中的 `apiKey` 与 `storeCode` 不匹配，或者该 API Key 在管理后台被停用/重置。
- **解决方案**：
  1. 登录 Web 管理端，进入 **系统设置 ➔ 门店管理**；
  2. 找到当前门店，检查其「E6对接状态」是否为“已启用”；
  3. 重新复制其对应的 API Key，粘贴覆盖至 `config.json` 中的 `api.apiKey` 字段；
  4. 确保 `api.storeCode` 与后台的门店代码保持严格的大小写一致（如 `SZ001`）。

### Q2.3 订单同步成功，但管理后台显示状态为“待映射 (状态码 1)”？
- **原因分析**：E6 单据中填写的医师工号（如 `D901`）在中药系统中尚未建立映射关系。
- **解决方案**：
  1. 属于正常业务流转拦截，**E6 端无需重复发送**；
  2. 门店管理员登录 Web 管理端，进入 **系统管理 ➔ 基础数据 ➔ E6医师映射**；
  3. 点击「新增映射」，录入外部医师工号 `D901`，并关联系统内的正式医生姓名；
  4. 保存后系统会自动激活该单据为「待确认」，药师即可开始分批排产。

## 3. 客户端与网络鉴权排障

### Q3.1 微信小程序提示：“request:fail url not in domain list”？
- **原因分析**：小程序的网络请求域名未在微信公众平台的合法白名单中登记。
- **解决方案**：
  - **开发调试阶段**：在微信开发者工具右上角点击「详情」➔「本地设置」➔ 勾选 **“不校验合法域名、web-view、TLS版本以及HTTPS证书”**；
  - **正式上线阶段**：登录微信公众平台后台，进入 **开发管理 ➔ 开发设置 ➔ 服务器域名**，将后端的正式全路径域名（如 `https://tcm.yourdomain.com`）填入 `request合法域名` 和 `uploadFile合法域名` 中。

### Q3.2 上传调配拍照凭证或高清处方时报错：“413 Payload Too Large” 或“网络请求超时”？
- **原因分析**：单张照片过大（超过 20MB），被 Nginx 网关或 Fastify 中间件拦截。
- **解决方案**：
  1. 检查 Nginx 配置文件 `/etc/nginx/sites-available/tcm.conf`，确保包含：
     ```nginx
     client_max_body_size 50M;
     ```
  2. 检查 `backend/.env`，确保 `MAX_FILE_SIZE_MB=30`；
  3. 重载 Nginx：`sudo nginx -s reload`。

### Q3.3 Web 管理端刷新页面后变成 404 Not Found？
- **原因分析**：Vue Router 使用了 HTML5 History 路由模式，而 Nginx 未配置降级指向 `index.html`。
- **解决方案**：检查 Nginx 对应 location 下是否缺少 `try_files` 配置，标准配置如下：
  ```nginx
  location /admin {
      alias /var/www/tcm/web-admin/dist;
      index index.html;
      try_files $uri $uri/ /admin/index.html;
  }
  ```

## 4. 短信与多渠道通知排障

### Q4.1 包裹生成后，顾客反映没有收到 6 位取货码短信通知？
- **排查步骤**：
  1. **检查订单手机号**：确认处方或包裹上登记的收件人手机号是否为合法 11 位中国大陆手机；
  2. **检查门店通知开关**：登录 Web 管理端 ➔ **系统设置 ➔ 门店管理**，确认本店的「取药短信通知」开关是否处于开启状态；
  3. **查看发送日志**：进入 **系统设置 ➔ 通知日志**：
     - 若状态为 `失败`，查看错误信息：
       - `isv.BUSINESS_LIMIT_CONTROL`：触发运营商防刷频控（单个手机号 1 小时内发送超过上限）；
       - `isv.AMOUNT_NOT_ENOUGH`：短信服务商（阿里云/腾讯云）账户余额不足；
       - `isv.SMS_SIGNATURE_ILLEGAL`：短信签名未审核通过或已被官方下线。
  4. **微信防骚扰拦截**：部分安卓手机（如华为、小米）骚扰拦截模块可能会将包含“提货码、快递”的短信归类到“推广信息/拦截骚扰”中，请提醒顾客在短信回收站或拦截箱中查验。

## 5. 核心业务与单据异常处理

### Q5.1 处方已经审核排产，就诊人临时要求退药作废怎么办？
- **处理规范**：
  1. **若加工单尚未开工（处于「待加工」排队中）**：
     - 门店管理员在「加工工作台」找到该加工批次，点击「取消计划」；
     - 进入「处方管理」将该处方标记为「已取消」；
  2. **若已开始煎煮调配（处于「加工中」）**：
     - 药师必须先在工作台上点击「工序作废」，备注作废原因（如“患者临时退药”）；
     - 将加工单与处方状态流转为作废，由财务介入人工核算已损耗的药材成本；
  3. **若已生成包裹（处于「待领取」）**：
     - 在「包裹管理」中点击「废弃包裹」，系统会自动注销该包裹的 6 位提货码与核销二维码，防止他人误领出库。

### Q5.2 顾客忘记或误删了 6 位取货码短信，到店如何取药？
- **处理规范**：
  - **通道 A（微信扫码）**：引导顾客直接用微信扫描药房前台放置的「顾客自提小程序码」，登录后在「我的包裹」中直接出示动态核销二维码给店员扫描；
  - **通道 B（人工核对取件）**：
    1. 店员进入 Web 管理端或小程序「包裹列表」；
    2. 搜索顾客**手机号后四位**或**患者姓名**；
    3. 严格核对就诊人身份信息（身份证或就诊挂号单）无误后，点击该包裹详情，直接执行「人工核销出库」并备注“顾客短信误删人工代核”。

### Q5.3 盘点时手滑录错了实盘数量怎么办？
- **处理规范**：
  - **初盘提交后、复盘未审核前**：初盘记录仅为待审状态，复盘人员在复盘界面点击「重新核对」，输入正确的二次实盘数量即可覆盖初盘错误；
  - **复盘已审核通过、已生成库存差异台账**：
    1. 门店管理员进入 **药房管理 ➔ 库存差异台账**；
    2. 找到因误操作生成的调增/调减流水；
    3. 点击「撤销差异」，录入撤回原因（如“初盘数量录错人工纠正”），系统会自动生成反向冲销流水并将账面库存对冲还原。
